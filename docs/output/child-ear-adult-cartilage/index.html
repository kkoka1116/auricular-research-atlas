Paired adult-anatomy comparison

Both heights were tested against the same ten confirmed-adult G3 cases with the earlier component architecture. Both produced a best single-case allocation of 2/4 units and pooled coverage of 2/4. The smaller target alone did not explain the difference from the earlier mixed-age experiment.
