Data intake and provenance

Three categories must remain distinct: synthetic, public_anatomical, and research_specimen. Do not put anatomical or specimen data into the synthetic results directory or describe patient scans as available donor grafts.

Before an anatomical pilot

Confirm actual file formats, mask labels, physical units, affine interpretation, laterality, subject identifiers and connected-component definitions. Preserve raw images and masks separately from derived meshes. A convex hull of cartilage can include empty space and therefore cannot replace a valid nonconvex containment check. Never feed a convex hull of anatomical cartilage to this demo's certificate and describe it as a certificate for the original anatomy.

Set aside all anatomy from each evaluation individual before method tuning. Record any surgeon-driven revision as a new development iteration and, where possible, use previously unused cases for revised evaluation.
